Changelog
=========

`19.0.1.0.0`
------------

- Initial release.

  - Workspace hierarchy: Space -> Project -> Folder -> Sprint -> Task.
  - Multi-view task handling: List, Board, Calendar, and Gantt.
  - Sprint-scoped team Chat and a global Inbox (public/private channels and
    direct messages).
  - Documents hub indexing task and chat attachments.
  - Notifications for assignments, mentions, and milestones.
  - Reporting with weekly/monthly filters and PDF/Excel export.
  - Project Billing: mark a project billable, set an hourly rate, and generate
    a draft customer invoice from logged task timesheets. Only one unposted
    invoice is allowed per project at a time -- update it as hours change
    instead of creating duplicates -- and posted invoices are permanently
    locked against further edits.
  - Configuration page: appearance (light/dark), Space and Project member
    access, per-project stage workflows, and an administrator-only system
    reset restricted to development environments.
