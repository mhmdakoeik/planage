Features

Everything a team needs to ship work

Planage brings project management, goals, chat, and billing together in one fast, native Odoo experience.

Multi-view tasks

Switch instantly between List, Board, Calendar, and Gantt — same data, whichever view fits the moment.

Goals & KPIs

Set strategic goals and link the measurable key results that show whether the work is actually moving the needle.

Real-time collaboration

Threaded task comments, project chat, and a live activity feed keep the whole team on the same page.

Workspace hierarchy

Organize work the way teams actually think: Workspace → Space → Folder → List → Task.

Zero-reload SPA

Built entirely in OWL for an app-like feel inside Odoo, with offline-safe sync so nothing gets lost on a flaky connection.

Smart notifications & inbox

Mentions, assignments, and milestones land in a unified inbox and notification center — never dig for updates again.

Time tracking & billing

Log hours against tasks and generate customer invoices directly from billable projects — no export/import round-trips.

Role-based permissions

Fine-grained User, Manager, and Admin access levels backed by real record rules — not just hidden buttons.

Access control

Permissions that match how teams work

Three built-in security groups, enforced with real Odoo record rules.

User

Day-to-day contributor

  • Views spaces, projects, and tasks they're part of
  • Creates and updates tasks, comments, and documents
  • Tracks time and receives notifications
Manager

Project & sprint owner

  • Full control over projects, sprints, and stages
  • Manages billing settings and generates invoices
  • Everything a User can do, plus team oversight
Admin

Workspace administrator

  • Creates and configures top-level workspaces
  • Full read/write/create/delete across the app
  • Resets and maintains Planage configuration
